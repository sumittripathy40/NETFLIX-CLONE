# Netflix Clone

A responsive Netflix landing page clone built with HTML and CSS, inspired by Netflix's homepage. The project recreates the main hero section, membership call-to-action, feature sections, FAQ layout, and footer.

## ✨ Features

- Netflix-inspired landing page design
- Hero section with email input and call-to-action buttons
- Feature sections highlighting TV viewing, offline downloads, streaming across devices, and kids' profiles
- Frequently Asked Questions section
- Footer with common navigation links
- Responsive viewport setup for different screen sizes

## 🛠️ Built With

- **HTML5** — page structure and content
- **CSS3** — styling and layout

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/sumittripathy40/NETFLIX-CLONE.git
   ```

2. Open the project folder:

   ```bash
   cd NETFLIX-CLONE
   ```

3. Open `index.html` in your browser.

No package installation or build step is required.
